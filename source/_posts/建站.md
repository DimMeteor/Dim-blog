## 用git连接github
先在本地仓库目录下启动cmd或者git bash
创建连接信息
``` bash
git config --global user.name "DimMeteor"
git config --global user.email "1592497663@qq.com"
```
建立远程链接
``` bash
git remote add origin git@github.com:DimMeteor/Dim-blog
```
修改远程链接仓库
``` bash
git remote set-url origin git@github.com:DimMeteor/Dim-blog.git
```
将仓库内容全部推入暂存区
``` bash
git add *
```
将嵌套仓库(引用了别的仓库)添加暂存权限(需重新推入)
``` bash
git submodule add https://github.com/D-Sketon/hexo-theme-reimu.git themes/reimu
```
将暂存区内容提交到header
``` bash
git commit -m "代码提交信息"
```
将暂存区内容提交到仓库
``` bash
git push origin master
```
